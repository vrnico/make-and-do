# 03 · Fake inventory

*Day 7. Not needed until then — here so you know it's coming.*

**Every prototype fakes something.** Hardcoded data, one working path, a wizard behind the
curtain, placeholder art, a temporary sound. That's legitimate — faking is how a fortnight
produces something that runs at all.

**What separates a prototype from a lie is that you know what you're faking and you say so.**

| What's fake | What'd it take to make it real | Does the fake change what they conclude? | Disclose? |
|---|---|---|---|
|  |  |  | ▢ |
|  |  |  | ▢ |
|  |  |  | ▢ |

**The rule: fake the effort, never the outcome.**

- *Placeholder art* — fake, obvious, changes nothing. Fine, unsaid.
- *One hardcoded path that looks like many* — changes what they conclude about scope. **Say it.**
- *A result that looks computed and is typed in* — changes everything. **Say it, every time,
  immediately.**

Faking how hard something was is a prototype. Faking whether it works is a demo that becomes a
lie the moment somebody believes it.
